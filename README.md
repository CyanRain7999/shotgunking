# SHOTGUN KING · 像素复刻 v2 (PWA)

横版像素国际象棋 Roguelike 爬塔游戏。你是手持军火库的**黑王**：移动一步或开火一次就推进一个回合，白色棋子按国际象棋规则逼近，击杀每层**白王**通关选卡，爬完 10 层获胜。

- 零依赖、纯静态：`index.html` + `game.js` + `sw.js`，无构建步骤
- PWA：可安装到桌面/主屏幕、离线可玩、强制横屏
- 桌面：鼠标连续角度瞄准（扇形随机弹丸）
- 手机横屏：点按开火、滑动移动、自适应整数缩放

## 主线章节（v13）

爬塔战斗是**主线**，按章节推进；**章节 + 模式双选后才可开局**（开始画面
先选章节、再选模式，出现「开始战斗」按钮）。**四个章节都支持全部八种模式**
（经典 / 无双 / 障碍 / 狙击 / 无尽 / **环城** / **夜袭** / **达阵**），美术随章节切换（像素艺术）：

- **第一章 · 王座之路**：国际象棋规则（兵/马/象/车/后/王 + 底座铭牌字母），
  经典深蓝棋盘。
- **第二章 · 楚河汉界**（紫禁深宫风）：**中国象棋**规则——红方按中国象棋规则
  逼近（兵/马/相/仕/车/炮/帅，含蹩马腿、塞象眼、炮隔山打、九宫与过河规则），
  击杀红帅通关。宫墙红棋盘 + 金色格线 + **石板路**：黑王与红帅站在石板上时，
  **一次移动距离 +1**（直线 2 格，中间须为空）。
- **第三章 · 平安京**（和风）：**将棋**规则——红方按将棋走法逼近
  （歩/香/桂/銀/金/角/飛/王，进入黑方半场**成金**升级：歩香桂銀→金将走法，
  角→龙马、飛→龙王），击杀王将通关。浅木地板 + 飘落樱花花瓣 + **樱花树**
  （可摧毁障碍）；随机生成樱花树。局内顶栏 **TUTOR 教程**按钮可随时查看
  将棋规则（走法表/成金/打入说明）。
- **第四章 · 一千零一夜**（沙漠王宫风）：**波斯象棋 Shatranj** 规则——红方
  按古波斯走法逼近（棋子采用**经典国际象棋大头像剪影** + 波斯微调：红玉主体 +
  头顶金新月 + 底座类型字母 P 兵 / A 象 / F 后 / N 马 / R 车 / S 王，一眼认出
  象=主教帽、后=三层王冠、马=马头、车=城堡、王=十字王冠），击杀沙赫通关。
  沙漠金砖棋盘 + 常驻**全屏精细飘沙**（多层细沙粒子 + 风中细丝）。招牌机制：
  - **擒王（裸王即胜）**：把红方杀到只剩王立即通关——不必杀王，清光护卫即可；
  - **小沙暴（常驻）**：敌方受击伤害按与黑王的距离衰减（每格 -12%，
    最低 50%）——近战武器（霰弹/火焰）更吃香；
  - **大沙暴（周期）**：每 3 个敌方回合席卷棋盘，**沙幕掩蔽随机格**
    （动态流沙盖住格子与其中棋子，行动不受影响）；**开火清除攻击路径上的沙幕**，
    爆炸吹散周围沙幕。

**进阶难度（全局叠加）**：主界面章节/模式下方可选（无 / I~X），详见下方表格。

**打入机制**（第三章）：击杀红子获得**持驹**（面板 HAND 栏，最多 3 枚），
按 `K` 或点击持驹槽选空格放入己方棋子（黑色駒形）。打入棋**不会移动**，是
**诱饵**：离它比离你更近的敌人会被吸引靠近它；打入后的**首回合（吸引回合）
不会被敌人吃掉**（蓝色光环标识），若未引爆则之后会被吃掉；**射击打入棋可将其
引爆**，造成以其为中心、该棋子走法射程 ×2 的范围伤害（歩/銀/金=2 格、桂=4 格、
香/角/飛=全场截断）。红方吃掉你的棋子后也会获得持驹并**打入**回来。

**精英棋子**（第二章）：落点在棋盘**交叉线（格点）**上，它是纯粹的 **2×2 单位**
——碰撞箱 = 以落点为中心的一圈四个格子，**攻击范围同样是落点这一圈格子**
（玩家踏入即受攻击；精英炮可隔山远程）；金色大环绘制在落点正中，与碰撞箱
严格对齐；生成时扫描空位，保证不与任何棋子/障碍重叠。

## 进阶难度（全局叠加）

主界面章节/模式下方可选择**进阶难度**（无 / I~X，手机横屏可用）：

- **全局叠加**：选高级自动囊括所有低级效果。
- **补偿**：等级 ≥3 激活「龙行」首次移动免费；≥6 激活「龙胆」首次击杀 +1 王冠；
  ≥9 激活「龙怒」每层首次攻击伤害 +1。

| 级 | 名称 | 效果 |
| --- | --- | --- |
| I | 穷兵黩武 | 战斗开始时额外生成一个「兵」 |
| II | 精兵良将 | 随机 2 个敌人血量 +2（红色标记） |
| III | 底火不良 | 霰弹枪当前弹药 -1 |
| IV | 瞄具锈蚀 | 所有武器散射角 +20% |
| V | 天塌地陷 | 随机一个不可摧毁障碍（钢铁色） |
| VI | 背水一战 | 所有敌人血量 +1 |
| VII | 君权谁授 | 王冠上限 -1 |
| VIII | 执牛耳者 | 白王（红帅）血量 +2 |
| IX | 一触即发 | 所有武器射程 -1 |
| X | 逐鹿中原 | 增加一个白王，需击杀所有白王 |

## 局内菜单

战斗顶栏右侧「MENU 菜单」按钮：随时返回主界面（重新选择章节/模式/进阶）。

## 无尽模式（独立模式）

与经典/无双/障碍/狙击并列的**第五种模式**：从第 1 层起无限爬塔（两章通用）。

- 每 **10 层为一个循环**：11 层（循环 2）从 **5 层基础**出怪，逐层增强，
  **15 层达到 10 层最大出怪**并持续到 20 层；
- 之后每个新循环都从 5 层基础重新开始、循环内第 5 位达最大；
- **每完成一个 10 层循环，所有敌人生命值 +1**（可无限累积）；
- **我方被动（卡牌/属性）每层照常叠加**，越打越强。

## 结束与返回

输了或赢了都会**默认自动返回主界面**（结束画面展示数秒；也可点「继续无尽
模式」直接开下一循环，或点「返回主界面」立即返回）。

## 残躯系统

击杀敌人获得其**残躯**（栏位 2，满了不再掉落）：使用后化为**黑色对应棋子**，
按对应走法**行进一次**——可吃掉终点格上的敌人（残躯吃子不再掉落新残躯）。
键位 `T` / `Y` 或点击面板残躯槽进入瞄准，点击可达格执行，点非法格取消。
第二章中残躯为黑色中国象棋棋子（卒/马/象/車/砲/士/将）按黑方规则行进。

## 主动道具（以撒式：复用 + 充能）

- **第 3 / 6 / 9 层结束**可选/替换主动道具（选择后仍可正常选强化卡）。
- 道具不消耗：击杀敌人充能（精英 +2），**充满即可释放**，之后继续充能。
- 面板中「ITEM 道具」行（弹药下方）与**底部 ITEM 按钮**双入口：像素图标 +
  名称 + 充能格 + 快捷键提示（桌面 `Q`，手机 `TAP`）；**充能满时整行/整按钮
  金色高亮**。点击或按 `Q` 释放。未持有道具时按钮显示「3/6/9 层」提示。
- 道具：`大炸弹` 3×3 爆炸 · `时间冻结` 敌方跳过回合 · `八向齐射` 8 方向射击 ·
  `王冠治疗` +2 生命 · `御前肃清` 随机消灭一名敌人。

## 战斗规则

- **白方（红方）半场开局**：敌方初始位置只出现在己方半场（棋盘上半 y 0–3），
  绝不越过中场线。
- **敌方分批行动**：每个敌方回合随机挑选一组棋子**同时**行动——最多 60%
  的棋子一起移动，至少 2 个棋子一起移动，其余按兵不动。
- **双语界面**：战斗界面全部英文保留原样（像素艺术），中文使用**正常系统字体**
  （黑体优先、宋体兜底）清晰直绘，不糊眼。
- **棋子辨识度**：第一章白方棋子带底座铭牌字母（P/N/B/R/Q/K）与差异化
  强调色；第二章红方为圆形汉字棋子（帅仕相马车炮兵）。

## 玩法

| 武器 | 锥角 | 射程 | 特性 |
| --- | --- | --- | --- |
| 1 霰弹枪 | 45° | 4 | 5 弹丸 |
| 2 集束霰弹 | 15° | 6 | 3 弹丸 |
| 3 弓箭 | 10° | 8 | 无限穿透 |
| 4 火焰喷射器 | 25° | 4 | 锥内全伤 + 灼烧 |
| 5 投弹手 | — | 3 | 鼠标投掷、随机弹跳一次、3×3 爆炸 |

模式：**经典**（五武器切换）/ **无双**（弹药无限）/ **障碍**（随机可破坏砖墙）/ **狙击**（专属狙击枪：2° 精度、无限射程、高伤害）/ **无尽**（每 10 层循环 + 全体敌人 +1 血）/ **环城**（上下左右互通：黑王移动、敌方滑行、弹道、炸弹全部绕环面——**黑王滑出边缘即绕到对面**（滑动/方向键均可），棋盘四边有脉冲箭头提示）/ **夜袭**（视野迷雾：**黑王身边 2 格敞亮、其余全黑**，迷雾外的敌人/威胁/事件不可见；**开火短暂照亮开火范围**（武器射程内），随后渐黑——先照亮再打，探索式战斗）/ **达阵**（宽 8 × 长 32 长条棋盘，视口随黑王前进显示当前 8 行，**瞄准/弹道锚定黑王**，**右侧进度条实时显示黑王在长条棋盘中的位置**；**白王镇守底线**（y=31 达阵区，不移位但威胁相邻格，其攻击范围清晰显示）；敌人沿长条均匀分布、密度不变数量逐层增加并追击黑王；**越底线（y=31）或生擒白王均达阵通关**；**每层通关奖励 2 张被动卡**）。

27 张升级卡：伤害/弹丸/射程/穿透/爆裂/龙息/吸血/荆棘/独头弹/双连发/爆头/护盾/时间裂隙……

## 操作

- 电脑：`左键` 瞄准开火 · `右键`/`WASD` 移动 · `1-5` 切枪 · `R` 装弹 · `空格` 循环武器
- 手机：`点按` 瞄准开火 · `滑动` 移动 · 底部按钮切枪/装弹

## 部署到 GitHub Pages

1. 新建仓库，把本目录的**全部文件**（`index.html`、`game.js`、`sw.js`、`manifest.webmanifest`、`icons/`）推到仓库根目录
2. 仓库 → Settings → Pages → Source 选 `main` 分支 `/ (root)` → Save
3. 等待 1–2 分钟后访问 `https://<用户名>.github.io/<仓库名>/`

所有路径均为相对路径（`./...`），部署在子目录（如 `https://user.github.io/repo/`）也无需改动。

## PWA 安装

- Android / Chrome：首次访问后点击右上角「安装到桌面」
- iOS Safari：分享 → 添加到主屏幕
- 安装后全屏横屏启动，断网也能玩（Service Worker 缓存 v2）

## 本地运行

直接双击 `index.html`，或：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 提示：Service Worker 需要 http(s) 环境，`file://` 打开时 PWA 功能不生效，游戏本身照常可玩。
