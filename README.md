# SHOTGUN KING · 像素复刻 v2 (PWA)

横版像素国际象棋 Roguelike 爬塔游戏。你是手持军火库的**黑王**：移动一步或开火一次就推进一个回合，白色棋子按国际象棋规则逼近，击杀每层**白王**通关选卡，爬完 10 层获胜。

- 零依赖、纯静态：`index.html` + `game.js` + `sw.js`，无构建步骤
- PWA：可安装到桌面/主屏幕、离线可玩、强制横屏
- 桌面：鼠标连续角度瞄准（扇形随机弹丸）
- 手机横屏：点按开火、滑动移动、自适应整数缩放

## 玩法

| 武器 | 锥角 | 射程 | 特性 |
| --- | --- | --- | --- |
| 1 霰弹枪 | 45° | 4 | 5 弹丸 |
| 2 集束霰弹 | 15° | 6 | 3 弹丸 |
| 3 弓箭 | 10° | 8 | 无限穿透 |
| 4 火焰喷射器 | 25° | 4 | 锥内全伤 + 灼烧 |
| 5 投弹手 | — | 3 | 鼠标投掷、随机弹跳一次、3×3 爆炸 |

模式：**经典**（五武器切换）/ **无双**（弹药无限）/ **障碍**（随机可破坏砖墙）/ **狙击**（专属狙击枪：2° 精度、无限射程、高伤害）。

27 张升级卡：伤害/弹丸/射程/穿透/爆裂/龙息/吸血/荆棘/独头弹/双连发/爆头/护盾/时间裂隙……

## 操作

- 电脑：`左键` 瞄准开火 · `右键`/`WASD` 移动 · `1-5` 切枪 · `R` 装弹 · `空格` 循环武器
- 手机：`点按` 瞄准开火 · `滑动` 移动 · 底部按钮切枪/装弹

## 部署到 GitHub Pages

1. 新建仓库，把本目录的**全部文件**（`index.html`、`game.js`、`sw.js`、`manifest.webmanifest`、`icons/`）推到仓库根目录
2. 仓库 → Settings → Pages → Source 选 `main` 分支 `/ (root)` → Save
3. 等待 1–2 分钟后访问 `https://<用户名>.github.io/<仓库名>/`

所有路径均为相对路径（`./...`），部署在子目录（如 `https://user.github.io/repo/`）也无需改动。

## PWA 安装

- Android / Chrome：首次访问后点击右上角「安装到桌面」
- iOS Safari：分享 → 添加到主屏幕
- 安装后全屏横屏启动，断网也能玩（Service Worker 缓存 v2）

## 本地运行

直接双击 `index.html`，或：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 提示：Service Worker 需要 http(s) 环境，`file://` 打开时 PWA 功能不生效，游戏本身照常可玩。

## 开发

```bash
node --check game.js        # 语法检查
node test_sim.js            # 逻辑测试（弹道/武器/模式/卡牌/不变式）
node test_dom.js            # 假 DOM 渲染冒烟测试
node test_deep.js           # 深度爬塔模拟（Boss 层/通关/无尽）
node test_shot.js           # 离屏渲染截图（手机横屏布局）
node make_icons.js          # 重新生成 PWA 图标
```
